# Acesso e Respeito

Projeto educativo sobre acessibilidade de pessoas com deficiência em motéis. Feito com HTML, CSS e JavaScript puro, com código simples para apresentação individual.

## Como usar

Abra index.html no navegador. Na lista educativa, digite um nome fictício e marque os recursos confirmados. Ver resultado exibe os pontos ainda não confirmados. Limpar restaura os campos.

A lista não avalia normas técnicas, não gera nota e não certifica o estabelecimento. Os dados não são enviados nem salvos. O mapa externo precisa de internet e não identifica motéis acessíveis.

## Arquivos principais

- index.html: conteúdo, tabela, formulário e mapa.
- style.css: aparência, Flexbox e adaptação ao celular.
- script.js: leitura das caixas e montagem da resposta.
- assets/acessibilidade.svg: ilustração local original.
- GUIA-APRESENTACAO.md: roteiro para estudar e explicar o código.

## Requisitos da atividade mantidos

- HTML5, charset, title, viewport, header, section, article, aside e footer.
- Títulos, parágrafos, abbr, imagem com alt e dimensões, links com target="_blank".
- Lista, tabela com th/tr/td e iframe externo.
- Formulário com label/for/id, inputs text e checkbox, placeholder, required, submit e reset.
- CSS externo, seletores universal, tag, classe e ID, cores, fontes e remoção de sublinhado dos links.
- Flexbox: direction, wrap, justify-content e align-items; media query para celular.
- JavaScript externo ao final do body, const/let, captura de dados, template literals, atualização do DOM com textContent, console.log e condições com === e !.

## Referência de contexto

Programa Turismo Acessível, Ministério do Turismo: https://www.gov.br/turismo/pt-br/acesso-a-informacao/convenios-e-transferencias/projetos-apoiados-pelo-ministerio-do-turismo/programa-turismo-acessivel
